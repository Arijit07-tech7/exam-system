## ✨ About The Project

**Premium Online Examination System** is a modern web-based exam platform designed to provide students with a smooth, fast and interactive examination experience.

The system focuses on:

⚡ Clean user experience
⚡ Modern glassmorphism interface
⚡ Responsive mobile-first design
⚡ Automated evaluation
⚡ Real-time examination flow

# 🌟 Key Features

| Feature            | Description                           |
| ------------------ | ------------------------------------- |
| 🔐 Student Login   | Secure student access system          |
| 📝 MCQ Examination | Interactive multiple-choice questions |

| 🧮 Auto Evaluation | Instant score calculation             |
